
# Questao 1 - Calculadora de Matrizes

## Descricao
Desenvolvimento de uma calculadora de matrizes utilizando a linguagem C.

## Funcionalidades

1. Escolher a quantidade de matrizes.
2. Informar as dimensoes e os elementos das matrizes.
3. Realizar soma.
4. Realizar subtracao.
5. Realizar multiplicacao.
6. Realizar divisao elemento por elemento.
7. Apresentar a matriz solucao.

## Tecnologias utilizadas

- Linguagem C
- Online GDB
- GitHub

## Como executar

1. Abrir o arquivo calculadora.c.
2. Compilar o programa utilizando um compilador C.
3. Executar o programa.
4. Escolher as opcoes do menu.

## Observacao

O programa verifica as dimensoes das matrizes e impede divisao por zero.
